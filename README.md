# Crianza Zarfer

Planificador de crianza Pokémon 6x31 y Pokédex de grupos huevo para el servidor **Diosesmon** (Cobblemon), con Zarfer de asistente y el minijuego de cartas **La Torre de Zarfer**.

## Descargar

Descarga **`CrianzaZarfer.zip`** de la [última versión](https://github.com/ZarferXekral/Crianza-Zarfer/releases/latest), descomprímelo y abre `CrianzaZarfer.exe` (Windows, usa Microsoft Edge WebView2).

La aplicación se actualiza sola: cuando hay una versión nueva aquí, Zarfer te avisa.
